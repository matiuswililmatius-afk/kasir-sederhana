# Simple Cashier (Kasir Sederhana)

## Description
This is a simple Python-based cashier program that calculates the total purchase for a single item. Perfect for learning basic Python and practicing coding.

## Features
- Input item name
- Input price per item
- Input quantity
- Calculate total purchase
- Display a receipt in the terminal

## How to Run
1. Clone the repository:
```bash
git clone https://github.com/matiuswililmatius-afk/kasir-sederhana.git


2. Navigate to the project folder:
```bash
cd kasir-sederhana

3. Run the kasir.py file:
```bash
python kasir.py

4. Follow the terminal prompts:
Enter item name
Enter price
Enter quantity
The program will display a receipt like this:

===== PURCHASE RECEIPT =====
Item    : [item name]
Price   : Rp [price]
Quantity: [quantity]
----------------------------
TOTAL   : Rp [total]
============================
Thank you for shopping!
